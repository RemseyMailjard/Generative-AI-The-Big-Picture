# Hands-On Exercise: Finance Agent with uv

This exercise shows how to create a small finance agent project with `uv`, `phidata`, `yfinance`, and Groq.

The goal is to build an AI agent that compares analyst recommendations and company fundamentals for DocuSign (`DOCU`) and Salesforce (`CRM`).

## Step 1: Install uv

Install `uv` if you do not have it yet.

**Mac / Linux**

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

**Windows (PowerShell)**

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Verify that it works:

```bash
uv --version
```

## Step 2: Create a New Python Project

Create a new project folder and move into it:

```bash
uv init finance-agent
cd finance-agent
```

This creates a new Python project with a `pyproject.toml` file.

## Step 3: Install Dependencies

Add the required packages:

```bash
uv add phidata yfinance groq python-dotenv
```

Your `pyproject.toml` will now include the project dependencies automatically.

## Step 4: Create the Script

Create a file named `finance_agent.py` and add the following code:

```python
from phi.agent import Agent
from phi.model.groq import Groq
from phi.tools.yfinance import YFinanceTools
from dotenv import load_dotenv

load_dotenv()

agent = Agent(
    model=Groq(id="llama-3.3-70b-versatile"),
    tools=[YFinanceTools(stock_price=True, analyst_recommendations=True, stock_fundamentals=True)],
    instructions=["Use tables to display data."],
    show_tool_calls=True,
    markdown=True,
)

agent.print_response(
    "Summarize and compare analyst recommendations and fundamentals for DOCU and CRM. Show in tables.",
    stream=True,
)
```

## Step 5: Create a .env File

Create a `.env` file in the project root:

```env
GROQ_API_KEY=your_api_key_here
```

## Step 6: Run the Script

Run the agent with:

```bash
uv run python finance_agent.py
```

## Expected Outcome

The agent should:

- fetch market and analyst data for `DOCU` and `CRM`
- compare recommendations and fundamentals
- present the output in tables
- show tool calls while it works

## Notes

- You need a valid Groq API key for this exercise.
- Market data availability depends on the upstream finance data source.
- If the output is incomplete, run the command again or try a narrower prompt.
